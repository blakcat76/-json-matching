# JSON Matching Application

Консольное приложение на C# для сопоставления товаров из двух JSON-файлов с использованием алгоритма нечеткого поиска (FuzzySharp).

## Описание

Приложение считывает данные из двух JSON-файлов с различной структурой и находит совпадения между ними на основе схожести названий товаров. Для поиска используется библиотека FuzzySharp с порогом схожести 80%.

## Быстрый старт

```bash
cd JsonMatching
dotnet build
dotnet run
```

Подробная документация находится в [JsonMatching/README.md](JsonMatching/README.md).

## Структура проекта

- `JsonMatching/` - консольное приложение на C#
  - `Program.cs` - основной код приложения
  - `itemsType2.Json` - входной файл с товарами (структура 1)
  - `products_page_279.Json` - входной файл с товарами (структура 2)
  - `result.json` - выходной файл с результатами сопоставления

## Технологии

- .NET 8.0
- C# 12
- FuzzySharp 2.0.2 (алгоритм нечеткого поиска)
