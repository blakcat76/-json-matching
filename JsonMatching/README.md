# JSON Matching Console Application

Консольное приложение на C#, которое выполняет сопоставление товаров из двух JSON-файлов с использованием алгоритма нечеткого поиска (FuzzySharp).

## Функциональность

Приложение:
1. Считывает данные из двух JSON-файлов (`itemsType2.Json` и `products_page_279.Json`)
2. Использует библиотеку FuzzySharp для поиска схожести названий товаров
3. Создает файл `result.json` с сопоставленными данными (ID и название из первого файла, название из второго файла)
4. Порог схожести: 80%

## Структура входных файлов

### itemsType2.Json
```json
{
  "items": [
    {
      "id": 1745,
      "name": "Пиво разливное имп. Averbode/Авербод (1л ПЭТ) Бельгия"
    }
  ]
}
```

### products_page_279.Json
```json
[
  {
    "Name": "Paulaner, Oktoberfest Bier, in can,  0.5 л",
    "Url": "https://winestyle.ru/products/Paulaner-Oktoberfest-Bier-in-can.html",
    "Region": "Германия, Бавария"
  }
]
```

## Структура выходного файла

### result.json
```json
[
  {
    "Id": 1745,
    "ItemName": "Пиво разливное имп. Averbode/Авербод (1л ПЭТ) Бельгия",
    "ProductName": "Paulaner, Oktoberfest Bier, in can,  0.5 л"
  }
]
```

## Требования

- .NET 8.0 SDK или выше
- NuGet пакет: FuzzySharp 2.0.2

## Сборка и запуск

### Сборка проекта
```bash
cd JsonMatching
dotnet build
```

### Запуск приложения
```bash
cd JsonMatching
dotnet run
```

## Обработка ошибок

Приложение обрабатывает следующие ошибки:
- Отсутствие входных JSON-файлов
- Некорректный формат JSON
- Любые другие непредвиденные ошибки

## Как работает алгоритм

1. Приложение загружает оба JSON-файла
2. Для каждого элемента из `itemsType2.Json` сравнивает его название с каждым названием из `products_page_279.Json`
3. Использует алгоритм FuzzySharp.Fuzz.Ratio() для вычисления процента схожести (0-100%)
4. Если схожесть >= 80%, добавляет пару (Id, Name) в результаты
5. Сохраняет результаты в `result.json`

## Примечания

- Образцы файлов `itemsType2.Json` и `products_page_279.Json` включены в проект
- Файл `result.json` создается автоматически при запуске приложения
- Кодировка UTF-8 с поддержкой кириллицы
