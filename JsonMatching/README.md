# JSON Matching Console Application

Консольное приложение на C#, которое выполняет сопоставление товаров из двух JSON-файлов с использованием алгоритма нечеткого поиска (FuzzySharp).

## Функциональность

Приложение:
1. Считывает данные из двух JSON-файлов (`itemsType2.Json` и `products_page_279.Json`)
2. Использует библиотеку FuzzySharp для поиска схожести названий товаров
3. Создает файл `result.json` с сопоставленными данными, где схожесть >= 80%
4. Создает файл `result2.json` с лучшими совпадениями для оставшихся товаров (без ограничения порога)
5. Исключает из `result2.json` ID и названия товаров, уже сопоставленные в `result.json`

## Структура входных файлов

### itemsType2.Json
```json
{
  "items": [
    {
      "id": 1745,
      "name": "Пиво разливное имп. Averbode/Авербод (1л ПЭТ) Бельгия"
    }
  ]
}
```

### products_page_279.Json
```json
[
  {
    "Name": "Paulaner, Oktoberfest Bier, in can,  0.5 л",
    "Url": "https://winestyle.ru/products/Paulaner-Oktoberfest-Bier-in-can.html",
    "Region": "Германия, Бавария"
  }
]
```

## Структура выходных файлов

### result.json (совпадения >= 80%)
```json
[
  {
    "Id": 1001,
    "ItemName": "Пиво разливное имп. Paulaner Oktoberfest ж/б (0.5л ПЭТ) Германия",
    "ProductName": "Paulaner, Oktoberfest Bier, in can, 0.5 л"
  }
]
```

### result2.json (лучшие совпадения для оставшихся товаров)
Содержит товары, не вошедшие в `result.json`, сопоставленные с лучшими доступными совпадениями без ограничения порога схожести. Исключает ID и названия товаров, уже использованные в `result.json`.

```json
[
  {
    "Id": 2002,
    "ItemName": "Пиво Stella Artois ст (0.33л) Бельгия",
    "ProductName": "Stella Artois Premium Lager, 0.5 л"
  }
]
```

## Требования

- .NET 8.0 SDK или выше
- NuGet пакет: FuzzySharp 2.0.2

## Сборка и запуск

### Сборка проекта
```bash
cd JsonMatching
dotnet build
```

### Запуск приложения
```bash
cd JsonMatching
dotnet run
```

## Обработка ошибок

Приложение обрабатывает следующие ошибки:
- Отсутствие входных JSON-файлов
- Некорректный формат JSON
- Любые другие непредвиденные ошибки

## Как работает алгоритм

### Этап 1: Генерация result.json (>= 80% схожести)

1. Приложение загружает оба JSON-файла
2. Для каждого элемента из `itemsType2.Json`:
   - **Нормализует текст** для лучшего сопоставления:
     - Удаляет пробельные символы `\t`, `\n`, `\r`
     - Удаляет "Пиво бутылочное", "Пиво разливное"
     - Удаляет "имп.", "ПЭТ"
     - Удаляет названия стран/регионов
     - Нормализует разделители в числах (0.5, 0,5, 0 5 → 05)
     - Конвертирует "ж/б" и "in can" → "can"
     - Удаляет "ст" (стекло) и "bottle"
     - Удаляет слова "beer", "bier", "lager"
   - Сравнивает нормализованное название с каждым нормализованным названием из `products_page_279.Json`
3. Использует алгоритм FuzzySharp.Fuzz.Ratio() для вычисления процента схожести (0-100%)
4. Выбирает лучшее совпадение для каждого элемента
5. Если схожесть >= 80%, добавляет пару (Id, ItemName, ProductName) в результаты
6. Сохраняет результаты в `result.json`

### Этап 2: Генерация result2.json (лучшие из оставшихся)

1. Создает список ID и названий товаров, уже сопоставленных в `result.json`
2. Для каждого элемента из `itemsType2.Json`, **не вошедшего в result.json**:
   - Нормализует текст так же, как на этапе 1
   - Ищет лучшее совпадение среди товаров из `products_page_279.Json`, **не использованных в result.json**
   - **Без ограничения порога** - выбирает товар с максимальной схожестью
   - Добавляет найденное совпадение в результаты (независимо от процента схожести)
3. Сохраняет результаты в `result2.json`

## Примечания

- Образцы файлов `itemsType2.Json` и `products_page_279.Json` включены в проект
- Файл `result.json` создается автоматически при запуске приложения
- Кодировка UTF-8 с поддержкой кириллицы
